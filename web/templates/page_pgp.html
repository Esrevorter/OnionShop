PGP public keys

This page explains how PGP fits into the marketplace. It is public information — no login, no forms, nothing you submit here.

What this site stores

Only your ASCII-armored PUBLIC key, uploaded from your account page after validation. The server checks the key structurally (real OpenPGP public-key block, at least one user ID, not revoked, not expired) and rejects anything containing private-key material before it is saved.

What this site will never do

  • Hold your private key — we do not accept it, ask for it, or store it.
  • Decrypt anything server-side. Decryption happens only on your own machine, with your own private key and passphrase.
  • Show your passphrase or session secrets to anyone.

How to get a key

Generate a key pair locally, then publish only the public half:

gpg --full-generate-key          # create a key pair (keep the private key local)
gpg --armor --export you@example.com > public.asc   # the PUBLIC block to upload

The uploaded block starts with -----BEGIN PGP PUBLIC KEY BLOCK-----. If yours starts with PRIVATE KEY BLOCK, this site will refuse it — that file must never leave your machine.

How messages stay readable only by you

Counterparties encrypt messages to your public key. Only your private key can open them, and it never touches this server: read and decrypt locally with your own GPG installation.
