Automated timers (hourly cron)

  • 12 h — unpaid orders are cancelled; the buyer is notified.
  • 3 days in escrow without shipment — automatic refund to the buyer's refund address.
  • Shipped + estimate + 3-day grace — auto-release to the vendor, unless a dispute is open.

Payment detection is polling only — never inbound webhooks. The hidden service is unreachable inbound by design.

Money invariants

  • Escrow transitions go through the pure state machine; the database CHECK enforces the same graph.
  • Ledger entries are double-entry, append-only, and idempotent (release:<order>, refund:<order>, withdraw:<id>). Replays are no-ops.
  • Payments confirm on an exact amount to the order's own subaddress. Overpayment is flagged for manual review and never auto-releases; underpayment asks for the delta.
  • Refunds and payouts are broadcast on-chain and recorded with their transaction hash.

OpSec rules that must not drift

  • Hidden service terminates on the Whonix-Gateway; the app runs on the Workstation. Never Tor-over-Tor.
  • With NGINX_BIND_IP=0.0.0.0, the host firewall must restrict 8080/8443 to the Gateway IP.
  • No client IP logging, no email, no third-party assets, no JavaScript (script-src 'none').
  • Self-signed ECDSA P-384 certificate with the exact onion SAN. No CA-issued certs, no SPKI pins, never advise bypassing warnings.
  • Only public PGP keys are stored; the server never decrypts anything.
  • Backups are age-encrypted to an offline recipient; restore drills are part of readiness, not optional.
